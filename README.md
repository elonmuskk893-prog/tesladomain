Analyze the ZIP file I provided carefully.

The ZIP file contains screenshots of the complete Tesla giveaway website, including the admin panel. I want you to use these screenshots as the design and functionality reference and recreate the website as closely as possible.

Requirements

Recreate the website based on the screenshots provided.

Match the exact visual style, color scheme, typography, spacing, layout, buttons, cards, and overall appearance shown in the screenshots.

Recreate all visible pages and sections shown in the screenshots.

Reproduce the admin panel shown in the screenshots, including its layout, navigation, controls, and functionality.

Include all animations, transitions, hover effects, loading effects, pop-ups, and other interactive elements visible in the screenshots.

Make the website fully responsive so it works properly on desktop, tablet, and mobile.

Match the screenshots as closely as technically possible rather than creating a generic Tesla giveaway design.

Analyze every screenshot before building so that no important section, feature, or UI element is missed.

Make sure the frontend and admin panel work together properly.

Preserve the same visual hierarchy and user experience shown in the screenshots.

Important

Do not simply make something inspired by the screenshots. Recreate the interface and functionality shown in them as accurately as possible.

Before making changes, inspect the entire ZIP file and all screenshots inside it, including the admin-panel screenshots, and use them as the primary reference for the implementation.

If something is visible in the screenshots but its exact functionality is unclear, implement the closest reasonable behavior while maintaining the same appearance and user experience.

Build the complete website rather than just a visual mockup.
